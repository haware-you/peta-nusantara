# Peta Nusantara

Edit `src/peta.template.html`, never `peta-nusantara.html` (generated by `npm run build`).

## Design Context

- [PRODUCT.md](PRODUCT.md): register (brand), users, purpose, brand personality, anti-references, design principles, accessibility. Read before any UI work.
- [DESIGN.md](DESIGN.md): the visual system, "The Hand-Tinted Chart": colour roles (every hue is a legend entry, controls are ink), typography, elevation, components, do's and don'ts. Tokens live in the three theme blocks at the top of the template and must stay in sync.
