# Source images

Twenty-two historical images gathered as reference material for the map and
its sibling timeline. **Nothing in the page renders them.** The plate is
inline SVG by construction, so these are research inputs, and
`.vercelignore` keeps them out of the deploy.

Every one is a Wikimedia Commons file. The table records where each came
from and what is known about its licence.

## Licence status: mostly unverified

Of 22 files, **2 have a confirmed licence** and **20 do not**. The
unverified rows were read from search results rather than from the Commons
file page itself, so the licence column below is a lead, not a fact.

This matters if any of these are ever published. Most are old enough to be
public domain on age alone, but age is an argument, not a check, and
CC-BY-SA files carry a credit requirement that has to be honoured on the
page that shows them. Before any of these appear in the built page:

1. Open the Commons page linked in the table.
2. Read the licence template on that page.
3. Record it here, replacing `unverified` with what the page actually says.
4. Carry any required credit into the page that displays the image.

The repository `LICENSE` (MIT) covers this project's own code and prose. It
does not cover these files, which belong to their respective authors and
institutions under their own terms.
