# Rupa huruf

Berkas di direktori ini dikemas bersama aplikasi dan dimuat saat mulai oleh
`id.nusantara.ui.TimelineApp`.

| Berkas | Rupa huruf | Lisensi |
| --- | --- | --- |
| `Marcellus-Regular.ttf` | Marcellus, oleh Brian J. Bonislawsky (Astigmatic) | SIL Open Font License 1.1 |
| `IBMPlexSans-Regular.ttf` | IBM Plex Sans (variabel), oleh IBM | SIL Open Font License 1.1 |
| `IBMPlexMono-Regular.ttf` | IBM Plex Mono, oleh IBM | SIL Open Font License 1.1 |

Ketiganya berlisensi SIL OFL 1.1, sehingga boleh disertakan dan disebarkan
bersama program ini. Salinan lisensi tersedia di
<https://openfontlicense.org/open-font-license-official-text/>.

Marcellus dipilih karena bentuknya mengikuti huruf pahat pada batu — sejalan
dengan prasasti, sumber paling pasti dalam data ini.
